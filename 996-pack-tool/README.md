# ws 996 打包工具

996 服务端母包、规则包、勾选包及客户端 Lua 保护工具，Python + Tkinter。

## 运行维护版 v0.115

解压完整项目后，普通打包可直接运行 `启动工具.bat`。需要加密/混淆时，先双击一次 `安装保护依赖.bat`，成功后再启动工具。安装脚本将依赖放在项目自己的 `.venv` 中，启动脚本优先使用该环境，不修改系统 Python 包；需要已有 Python 3.10+ 或 uv。

也可在自己的 Python 环境中手动执行：

```console
python -m pip install -r requirements.txt
python ws_pack_tool.py
```

已有 uv 可使用：

```console
uv run --with lupa==2.8 python ws_pack_tool.py
```

代码使用 Python 3.10+ 语法，需要 Tkinter；本次自动验证环境为 Python 3.12 / Lupa 2.8。尚未在 Windows 真机或冻结 EXE 中直接运行。两项保护开关均关闭时，普通打包不依赖 Lupa；保护开启时，Lupa 的 Lua 5.1 后端用于构建期语法检查，游戏中只部署生成的 Lua。

新入口与旧工具放在同一目录时，继续使用原 `.group`、`.manifest`、`.global_filter.json`、`.ui_config.json`。不要删除这些个人配置和组内安全模板。源码仓库没有携带用户的运行配置。

## 操作

- 服务端继续使用母包、规则、勾选三种入口；最终选中的 Lua 才进入保护处理，其他文件原样打包。母包安全文件、空目录、过滤及规则语义保持。
- 文件区域右侧“开启加密”“开启混淆”是两端共用开关，初始均关闭，状态自动保存。任一开启均先删除业务注释并保留换行及行号。只开混淆也删除注释。
- 客户端行位于服务端导出目录下面、母包上面。填导入文件/目录和导出文件夹，点击“加密/混淆”。递归输出 Lua 相对路径，不添加导入目录名，不输出非 Lua，不生成 ZIP。
- 客户端路径随打包组保存，成功导出后自动记录，也可用“保存组”保存。原源码不改，导入/导出不允许重叠。已有输出只替换本次同名 Lua，其他旧文件保留，不清空输出目录。
- 输入按严格 UTF-8（含 ASCII）或 GBK 识别并保留原字节编码，不统一转码。BOM、shebang、字节码、已知加密壳、未支持语法和名称敏感反射明确报错，不静默退回明文。
- 正在处理时锁定主界面，任务选项与路径冻结。进度窗口可取消，等待当前文件结束后清理/回滚。ZIP 完成并验证后才替换旧 ZIP；客户端所有 Lua 完成处理后再提交，普通提交失败会恢复旧输出。
- 本地摘要记录保存在工具旁 `.build_reports`，不进入游戏发布包，不保存密钥、明文或私有改名表。

## 安全与限制

加密使用源码 ChaCha20、自包含 Lua 加载器，恢复原执行环境，加载时解密一次；重新加载文件会重新解密。密钥随壳提供，目标是提高阅读/还原成本，不是不可破解或防篡改保证。长度/Adler-32 仅检测意外损坏。每次重新保护输出随机化，源码变化基线仍依据处理前文件；本轮未加入产物缓存。

混淆器支持 Lua 5.1 兼容语法，只改有明确词法绑定的局部名，保留全局、字段、字符串及行号。常规模块/API 不需要维护名称白名单；不支持任意动态构造的名称敏感反射。已知/可疑 debug 别名及局部/上值反射会拒绝；日志中的局部名称可能改变，不能据此编写业务分支。LuaJIT 扩展语法不是本轮承诺范围。

已有引擎位运算模块时加载器自动加速，否则使用纯 Lua 算术后备，不新增游戏部署端原生依赖。大文件/重复加载仍有开销，详见验证报告。保留必要的内嵌第三方 MIT 许可。

客户端提交带回滚，不代表断电/强制结束进程也具备整目录事务保证。若回滚不完整，会保留恢复目录并报出位置；不要直接删除恢复目录。

`scripts/verify_framework.py <快照根目录>` 可针对 `docs/framework-audit.json` 指定的 40 份原始文件核对 Git blob SHA、四组合变换和两后端编译，不执行完整框架。

## 结构

| 模块 | 职责 |
| --- | --- |
| `ws_pack_tool.py` / `wspack/app.py` | 入口、现有界面和文件树交互 |
| `models.py` / `store.py` | 数据模型和配置持久化 |
| `filters.py` / `scanner.py` / `collector.py` | 原过滤、变化扫描和三种文件收集 |
| `archive.py` / `pipeline.py` | 后台桥接、暂存保护、ZIP和客户端文件提交 |
| `client.py` / `task_ui.py` | 独立客户端入口、公共任务状态和完成处理 |
| `lua_syntax.py` / `protection/` | 词法/作用域处理、字节保护和Lua加载器 |
| `dialogs.py` / `widgets.py` | 原有弹窗与控件 |

## 原始基线

`ws_pack_tool_v114.py` 是用户提供的 v0.114 原始源码，保持原字节，作为结构整理和功能回归的对照。运行：

```console
python ws_pack_tool_v114.py
```

Python 需要包含 Tkinter。运行配置保存在程序旁边；个人路径、打包组、安全模板及基线数据不进入仓库。

升级在 `upgrade/lua-protection` 分支实施，分开记录结构整理与 Lua 保护功能；`main` 保留原始基线。`scripts/extract_v114.py` 是一次性机械迁移证据，禁止对维护版重新执行覆盖。
